Advanced Settings

Nothing here is needed for normal use. Changes take effect the next time you start the app.

Use another server

Point this app at a controller server running somewhere else — a NAS, a Raspberry Pi — instead of running its own in the background. Leave it empty to run this computer's own player engine, which is what almost everyone wants.

Must start with http:// or https://. Anything else is ignored. If the server cannot be reached, the app says so and offers to try again — it will not quietly start its own server instead.

Serve on the local network

Normally this app's player engine is reachable only from this computer. Turn this on to let phones, tablets and other computers on your network open it in a browser.

There is no password on this. Anyone who can reach this computer on your network can control your Roon playback and browse your library. Only turn this on for a network you trust. To expose it beyond your own network, put it behind a reverse proxy that adds authentication.

Ignored while a server address is set above: the app is not running its own engine, so there is nothing here to share.
