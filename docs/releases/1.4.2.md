# Songr 1.4.2

Songr 1.4.2 fixes collection browsing and includes the library navigation changes
prepared since 1.3.0. Versions 1.4.0 and 1.4.1 remain withdrawn.

- Library collections, composer compositions, recordings, tag contents and long
  albums use continuous lists. Filtering and sorting operate on complete
  collections, with no manual page buttons.
- Composer, recording and genre actions use inline controls. Album track numbers
  come from Roon's labels or track metadata rather than list position.
- Settings → Library navigation controls the main buttons and their order.
  Unpinned pages remain in More; these choices are shared through the Songr server.
- Tagged albums and artists use the standard detail pages. Selection preserves
  the exact current Roon row, including recordings with identical titles.
- Album artwork loading, macOS startup, nested-page layout and return navigation
  include the corrections prepared since 1.3.0.
- Removed obsolete catalog, Canvas and action-modal code, an unused album timeout
  allowance and unsafe cleanup of an old configured directory.

Existing application identity, pairing and settings are retained when upgrading.
Playlists remain hidden because the public API does not reliably identify which
playlists can be opened. Changes to Roon tags require refreshing the Songr page.
