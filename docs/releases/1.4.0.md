# Songr 1.4.0

Songr 1.4.0 improves first-run setup and library browsing. These changes are
new since the public 1.3.0 release.

- **Album artists / All artists:** switch between album-credit groups and
  the complete Artists list. The selection is remembered.
- **Genre previews:** genre pages show an Artists row and an Albums row,
  each with a More link to its complete list.
- **Pinned library controls:** headings, artist-mode controls and Sort stay
  available while browsing long lists.
- **Clearer setup:** show Core discovery and connection progress, provide
  guidance when no Core is found, and finish setup when the Core pairs.
  Local playback through Roon Bridge is optional.
- **Navigation fixes:** restore album-artist addresses after a reload and
  preserve the correct return context when opening albums from the palette.
- **Responsive Library:** preserve complete lists across scope changes and
  prepare their layout before scrolling. Returning to Albums keeps its Shuffle
  order; choosing Shuffle again creates a new order.
- **macOS startup:** wait for Electron initialization before handling Dock
  activation or another launch, preventing a main-process startup exception.
- **Clean installer builds:** discard obsolete compiled files left by older
  source checkouts before building the current version.

The desktop application retains its existing Songr identity and profile.
