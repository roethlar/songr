# Songr 1.4.1

Songr 1.4.1 improves library navigation, artwork loading and playback controls. It includes the changes prepared for the withdrawn 1.4.0 release; 1.3.0 is the previous stable release.

- **Choose your library buttons:** Settings → Library navigation controls which pages appear on the main row and their order. More keeps the remaining pages reachable on smaller screens. These choices persist on the Songr server and are shared by its desktop and browser clients.
- **More useful collection pages:** Tracks, Composers, Tags and My Live Radio have direct navigation, filtering and sorting. Tracks also supports sorting by its displayed artist credits, with correct loading of lists larger than one page.
- **Consistent playback and navigation:** tagged albums and artists use the familiar Songr pages. Composer pages lead to compositions and recordings. Tracks and recordings have inline Play, Queue and More controls, preserving the exact selected row even when titles and credits match.
- **Artist and genre browsing:** a compact Album / All control switches between album artists and all artists. Genre pages show artist and album previews with links to their complete lists.
- **Artwork and responsiveness:** visible album covers take priority over obsolete requests, temporary artwork failures recover, and prepared library layouts keep page changes and scrolling responsive.
- **Recently played:** cards now open a search for the recorded title so you can select the current result. They do not start playback automatically.
- **Clearer settings and setup:** settings are grouped by purpose, Roon options are available in the main Settings dialog, and first-run setup shows Core discovery and pairing progress.
- **Startup and navigation fixes:** prevent the macOS window-initialization error, keep the playback bar visible on nested Library pages, and preserve album/artist return paths and prepared album-grid geometry.

Upgrade the desktop application or server normally; existing application identity, pairing and profile are retained.

Playlists are hidden because Roon’s public API cannot reliably distinguish supported playlists from smart playlists. Tag edits made in Roon are not pushed live into an already open Songr page.
