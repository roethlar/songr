## Coverage and provenance

- All ten currently reachable library navigation sections are represented, including both artist modes.
- Additional views include Search, album-artist collection, album, track selection, album selection, Queue, Controller settings, Library navigation settings and About.
- No separate Now Playing page exists; the playback dock appears in the app captures. Track Info has been removed, and Playlists has no available UI.
- Not recaptured: artist/genre/composer/tag detail subpages, Search selection, zone selection/grouping, expanded Roon options and native server/sharing settings.
- Live radio is experimental and returned No Results; radio playback has not been verified. Bookmarks was empty.
- These are real-library captures from one isolated Electron client connected to the existing app engine. Only client-local theme and transient navigation, search, scrolling and selection changed. No playback, queue, saved items, shared preferences, pairing or installed-app changes were made.
- Captures document the interface and coverage; they are not a UI, playback or performance test campaign.

All images are direct, unedited captures. No older images are presented as current. Earlier capture sets remain separate from this release gallery.
