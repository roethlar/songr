- Track Info remained pending at capture and appears only under Observations. Source inspection found the missing listener; the terminal timeout state was not captured. It is not counted as a completed normal detail view.

- Favorites is genuinely empty. Live radio shows Roon’s “No Results” response; no station has been invented for the gallery.
- Playlists has no available UI and is not represented by a fabricated screenshot.
- There is no standalone Now Playing page. The persistent playback dock is visible throughout the app captures; Queue, Zones and grouping have their own captures.
- Native desktop Advanced Settings is always dark and is included once. Its server-address and network-sharing controls belong to that separate desktop window.
- The images are original captures, not edited or composited. A bounded sample was visually inspected; the gallery does not claim a UI test campaign.
